# Voltrush

Voltrush meme coin web app: free daily spin, quests, leaderboard and on-chain trust checks.

Runs as a Streamlit app that renders `voltrush.html` full-screen.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

1. Go to [share.streamlit.io](https://share.streamlit.io)
2. **New app** → pick this repo (`voltrush`) and main file `app.py`
3. Deploy — every push to `main` auto-redeploys
